## Структура и воспроизводимость

- Проекты, направления ссылок, расположение Core/Features/модулей и
  модель результатов соответствуют [architecture.md](architecture.md).
- Общие и тестовые `.props` импортируются, версии пакетов централизованы;
  рабочие проекты используют `net10.0`.
- С чистого checkout выполняются документированные restore/build/test/run.
- Пустая БД создаётся автоматически; внешний сервер БД не нужен.
- README содержит действующий контракт, команды и полный пример работы API.
- Нет заранее внесённых дефектов: исходная версия должна быть корректной.

Тесты срока используют управляемое время. Проверка периода не требует
настоящего ожидания 10 секунд в каждом тесте. Сбои проверяются управляемым
воспроизведением, а не случайными падениями.

## Граница следующей задачи

В исходной версии нет выбора издателя. В будущей доработке уникальность
меняется на пару «издатель + владелец», а правила регистра, Pending,
Issued и повторной подачи после Rejected сохраняются внутри этой пары.
ТЗ будущего PR и материалы интервьюера не являются требованиями к исходной
реализации и подготавливаются отдельно.
